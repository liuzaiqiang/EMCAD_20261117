# 小器官感知的困难区域监督：实现与消融说明

当前项目使用基础 EMCAD 与训练期辅助损失，**不声称当前已测得 Dice 提升**。

## 实际接入与定义

辅助监督不改变基础 EMCAD 的网络参数、前向结构、输出头、推理及指标代码。开关为 `0` 时，Synapse 保留原 0.3×CE+0.7×Dice 的监督组合，ACDC 保留原 `supervised_loss`，二分类保留原结构损失；新辅助损失函数不被调用。`SMALL_TARGET_HARD_SUPERVISION=0` 使用原始 EMCAD 网络与原训练损失。

开关为 `1` 时，仅对最终头 `P[-1]` 加入一个**难分前景辅助项**。多类输入 `[B,C,H,W]` 时，背景类 0 被排除；按每张训练图像、每个存在的前景类分别计算。二分类输入 `[B,1,H,W]` 时，前景掩膜视作唯一目标类；这适用于息肉、皮肤病灶、乳腺病灶和细胞，论文中不能一概称其为“器官”。缺席类别不构造伪标签，也不贡献辅助损失。

对前景类 `c`，令真值面积占整图比例为 `a_c`，正确类别预测概率为 `p_t`。每类的辅助项是前景像素上 `-log(p_t)·stopgrad((1-p_t)^2)` 的平均，再乘 `clip(sqrt(0.10/a_c),1,3)`。最后对当前 batch 内存在的前景类求平均。区域小的类别最多获得三倍面积权重；低置信度的真前景像素获得更大难度权重，因此机制直接针对漏检倾向。面积只从**当前训练标签**计算，不读取验证或测试标签。计算使用 float32，兼容 AMP。

辅助项只计算一次，并乘 `0.05×原监督组数` 加到总损失。原监督项在 mutation/deep/last、二分类 paper 等模式中本来就是各组直接求和；乘组数使新增项相对各模式的尺度更接近。0.10、3、2 和 0.05 是本次冻结的候选超参数；若后续调节，必须记录成新的训练条件并重新配对比较。这个构造受 [Focal Loss（ICCV 2017）](https://openaccess.thecvf.com/content_iccv_2017/html/Lin_Focal_Loss_for_ICCV_2017_paper.html)、[Tversky loss](https://arxiv.org/abs/1706.05721) 和 [Unified Focal Loss](https://pubmed.ncbi.nlm.nih.gov/34953431/) 的不平衡监督思想启发。**难度权重用了 stop-gradient，因此不是标准 Focal Loss 的完整梯度；面积加权与前景类别平均是本工程的组合实现，不能宣称发明 focal 或类别重加权。**

## 12 个数据集的代码入口

| 数据集 | 训练路径 | 辅助损失形式 |
|---|---|---|
| Synapse | `train_synapse.py → trainer.py` | 多类，忽略背景 |
| ACDC | `train_acdc.py → utils/acdc_utils.py` | 多类，忽略背景 |
| BKAI、ClinicDB、ColonDB、ETIS、Kvasir | `train_polyp.py → utils/polyp_utils.py` | 二分类前景 |
| ISIC2017、ISIC2018 | `train_isic.py` 复用 Polyp 训练器 | 二分类前景 |
| BUSI | `train_busi.py` 复用 Polyp 训练器 | 二分类前景 |
| DSB18、EM | `start_train_cell.sh` 复用 Polyp 训练器 | 二分类前景 |

六个训练启动脚本都接受 `SMALL_TARGET_HARD_SUPERVISION=0/1`，默认 `1`；设置为 `0` 可进行原始 EMCAD 消融。Cell 包装器向 Polyp 启动器传递变量。该开关进入训练 `config.json` 和实验路径。推理没有新增损失操作或模型参数，因此测试脚本无需单独的开关。

示例：`SMALL_TARGET_HARD_SUPERVISION=1 bash sh/run_seed_queue.sh synapse 2222 3407 5678`。

## 必要消融与结论边界

| 困难区域监督 | 实验组 |
|---:|---|
| 0 | 原始 EMCAD |
| 1 | EMCAD+困难区域监督 |

检查开启监督相对原始 EMCAD 的**患者/图像级配对 Dice**，至少跨多个 seed，并报告每类 Dice、灵敏度、精确率、HD95/ASD、整体 Dice 和失败案例。若仅提高召回却增加较多 FP，总 Dice 仍可能下降；不能只展示小器官改善。当前 Synapse 训练器用 `test_vol` 逐 epoch 选最优权重；正式论文必须确认它是验证集，若是测试集则需要独立验证方案，不能将其结果称为未参与选模的测试性能。
