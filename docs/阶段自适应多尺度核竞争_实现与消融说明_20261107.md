# 阶段自适应多尺度核竞争：实现与消融说明

适用分支：`261107_nrgz_jdzsydcdhjz`。本文件说明当前实现和待验证假设，**不报告不存在的 Dice 增益**。

## 计算位置与公式

`lib/decoders.py` 的四个 `MSCB` 原来通过 `MSDC` 产生 1×1、3×3、5×5 深度卷积分支，并直接相加。开关 `stage_adaptive_kernels=1` 时，四个解码阶段各有一套独立的核竞争参数。每个阶段将进入 MSDC 的扩张特征做全局平均池化与最大池化，拼接后通过小型两层 MLP 得到该图像的各分支 logit。沿分支维 softmax 后乘分支数 K：

`w_i = K · softmax_i(MLP([GAP(x), GMP(x)]))`，`dout = Σ_i w_i · MSDC_i(x)`。

权重对同一图像、同一阶段的所有空间位置及通道共享；它们随输入图像和阶段改变。**这不是逐像素动态卷积核，也不改变 1/3/5 卷积核本身的权重或采样位置。**末层 MLP 的权重和偏置零初始化，使初始 `w_i=1`，此时与原分支直接求和相同。选择器初始化隔离随机数状态，同一 seed 下原有层的初值不会因新增参数而变化。`stage_adaptive_kernels=0` 时不创建选择器，原求和路径和 state_dict 键保持原样。

CAA 开关独立控制 EUCB；`USE_CONTENT_AWARE_ANTIALIAS=0 STAGE_ADAPTIVE_KERNELS=0` 只实例化原始 EUCB 和原始 MSDC 求和。新模块只支持 `add=True`；若同时选用旧 `--concatenation` 模式，会直接报错，避免论文实验含糊地把拼接与核竞争混为一谈。

| 任务 | 数据集 | 训练启动器 | 测试结构恢复 |

| 皮肤病灶 | ISIC2017、ISIC2018 | `sh/start_train_isic.sh`，由 `DATASET_NAME` 选取 | `test_isic.py` 经通用测试入口恢复配置 |

这些是 12 个数据集的**代码覆盖**，不是 12 个数据集都已完成训练或得到增益。旧 checkpoint 的配置若没有新字段，测试默认按 `0` 构建旧结构；新 checkpoint 的字段会由配置恢复，且结构与显式测试参数冲突时被拒绝。

## 四组必要实验

五个训练启动器以及 Cell 包装启动器均接受环境变量 `STAGE_ADAPTIVE_KERNELS=0/1`，默认 `0`。CAA 沿用 `USE_CONTENT_AWARE_ANTIALIAS=0/1`。通过 `run_seed_queue.sh` 启动时，环境变量会传入相应启动器。例如 `USE_CONTENT_AWARE_ANTIALIAS=1 STAGE_ADAPTIVE_KERNELS=1 bash sh/run_seed_queue.sh synapse 2222 3407 5678`。

| CAA | 核竞争 | 可归因的实验组 |
|---:|---:|---|
| 0 | 0 | 原始 EMCAD |
| 1 | 0 | EMCAD+CAA |
| 0 | 1 | EMCAD+核竞争 |
| 1 | 1 | EMCAD+CAA+核竞争 |

只有 `Dice(0,1)−Dice(0,0)` 和 `Dice(1,1)−Dice(1,0)` 在同一划分、同一 checkpoint 选择规则、多个配对 seed 与病例级统计中稳定为正，才支持“单独与配套均涨点”。需要同时报告每类 Dice、HD95/ASD、参数量、FLOPs、推理耗时和失败病例。核竞争已有相近的选择性卷积/注意力研究，论文应准确引用相关工作；本实现的可检验贡献是**在 EMCAD 四个 MSDC 阶段、与 CAA 独立开关的输入条件尺度选择**，不能声称发明了动态核选择范式。

Synapse 当前 `trainer.py` 使用 `test_vol` 做逐 epoch 模型选择。如果该列表在你的实验协议中属于测试集，就不能将这样选出的 best checkpoint 结果宣称为独立测试性能；正式实验须事先明确验证/测试划分。
