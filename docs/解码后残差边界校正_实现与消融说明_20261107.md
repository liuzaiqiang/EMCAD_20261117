# 解码后残差边界校正：实现与消融说明

适用分支：`261107_nrgz_jmhccbjjz`。本文件是实现说明与实验设计，**不包含尚未测得的 Dice 增益**。

## 精确接入位置与作用范围

EMCAD 的 `lib/decoders.py` 输出 `d4,d3,d2,d1`。本模块只接在 `lib/networks.py` 的 `d1 → out_head1` 之间，处理 `d1` 的 1/4 分辨率特征，不改变 `d4/d3/d2`、三个较粗预测头、最后的四倍双线性 logits 插值、损失或推理后处理。多输出训练中，所有包含 `p1` 的监督组合都可能得到模块梯度；其他头本身仍遵循原路径。

`lib/boundary_refinement.py` 中的固定 Sobel x/y 核对每个通道的 d1 特征求局部梯度。按通道平均并用该图的空间平均值归一化，得到 `[0,1]` 内的局部变化强度 `e`。一个可学习 1×1 门控生成 `g=e·sigmoid(Conv1×1(e))`，使近乎平坦位置的修正趋零。另一路由 3×3 深度卷积、SiLU 和 1×1 卷积生成残差 `r(d1)`；输出为：

`d1' = d1 + tanh(alpha) · g(d1) · r(d1)`。

`alpha` 初始化为 0.1，1×1 残差投影零初始化，因此新模块初始化时**精确等于恒等映射**。新增分支的随机初始化隔离在局部 RNG 上，同一 seed 下原 EMCAD 参数初值不受开关影响。`residual_boundary_refinement=0` 时模块完全不实例化，`state_dict` 没有该模块的参数或 Sobel buffer，前向仍直接执行 `out_head1(d1)`。CAA 由已有 `caa_mode=off/caa` 独立控制；两个开关均为 0 时，模型实例中不包含 CAA 或残差边界校正模块。

**严格表述：**Sobel 在这里提取的是解码特征的梯度代理，可能含有真实器官边缘、纹理或噪声。代码没有使用真值边界图、没有显式边界损失，也不能保证只修正真实边界。所谓“边界校正”是结构设计假设，须以 Dice、HD95/ASD、边界可视化及消融证明其实际作用。现有边界辅助学习和频率/边缘精炼研究应如实引用，例如 [BoundarySeg（2025 预印本）](https://arxiv.org/abs/2505.09829) 与 [PFESA（MICCAI 2025）](https://papers.miccai.org/miccai-2025/paper/3694_paper.pdf)；不得把 Sobel、门控或残差卷积宣称为本论文首创。

## 12 个数据集接入

所有正式训练启动器都接受 `RESIDUAL_BOUNDARY_REFINEMENT=0/1`，默认 `0`，并保留原有 `USE_CONTENT_AWARE_ANTIALIAS=0/1`。Synapse、ACDC、Polyp、ISIC、BUSI 的 Python 训练入口保存该字段到 checkpoint 相邻的 `config.json`，测试入口按训练配置恢复。DSB18/EM 的 Cell 启动器复用 Polyp 训练和测试路径，变量会继续传递。旧 checkpoint 没有新字段时按 `0` 恢复旧结构。

| 入口 | 数据集 |
|---|---|
| Synapse | Synapse |
| ACDC | ACDC |
| Polyp | BKAI、ClinicDB、ColonDB、ETIS、Kvasir |
| ISIC | ISIC2017、ISIC2018 |
| BUSI | BUSI |
| Cell（复用 Polyp） | DSB18、EM |

例如：`USE_CONTENT_AWARE_ANTIALIAS=1 RESIDUAL_BOUNDARY_REFINEMENT=1 bash sh/run_seed_queue.sh synapse 2222 3407 5678`。这只说明启动器覆盖 12 个数据集，不表示已经在全部数据集测得提升。

## 发论文所需的最小消融

| CAA | 边界校正 | 模型 |
|---:|---:|---|
| 0 | 0 | 原始 EMCAD |
| 1 | 0 | EMCAD+CAA |
| 0 | 1 | EMCAD+边界校正 |
| 1 | 1 | EMCAD+CAA+边界校正 |

必须分别比较 `Dice(0,1)−Dice(0,0)` 和 `Dice(1,1)−Dice(1,0)`。固定病例划分、预处理、骨干预训练、轮数、seed、优化器、学习率、checkpoint 选择、评估代码及阈值，使用多 seed 的配对病例指标，并报告类别 Dice、HD95/ASD、参数量、FLOPs、耗时和失败病例。只在组合组提升时只能写组合有效；若只有 HD95 改善，不能写 Dice 提升。Synapse 当前训练器使用 `test_vol` 逐 epoch 选择 best checkpoint，正式论文必须先确认它在实验协议中是验证集还是测试集，避免用测试数据选择模型。
