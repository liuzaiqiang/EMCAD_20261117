# CCF-B 会议与医学图像分割投稿判断

> 适用对象：医学图像分割、EMCAD 类编码器-解码器改进、注意力模块、多尺度特征融合、2D/2.5D/3D 分割实验。
>
> 判断日期：2026-09-25。会议官网的年份不等于当前仍开放投稿；最终应以当届 CFP 的投稿截止时间为准。

## 一、先给结论

### 最适合优先考虑

1. **MICCAI**：医学图像计算和计算机辅助手术，研究问题与医学图像分割直接匹配。
2. **BIBM**：生物信息学与生物医学，医学图像分析和分割可以作为明确主题投稿。
3. **ECCV**：可以投，但要把贡献写成具有通用计算机视觉价值的方法，不能只是“在几个医学数据集上提升 Dice”。

### 有条件适合

- **ICASSP**：适合把核心贡献放在图像/信号处理、频域建模、噪声鲁棒性、低层视觉或医学影像信号分析上。
- **ICME**：适合医学视频、3D 医学影像、多模态医学数据、医学图像与文本/视频联合分析。
- **IJCAI**：适合有明显通用人工智能方法创新的论文；普通分割网络小改动通常不够。
- **ICRA**：只有在手术机器人、机器人视觉、术中感知或三维场景理解是主问题时才合适。
- **Eurographics、EuroVis、PG、SGP、EGSR**：只有当论文主要贡献是医学可视化、几何处理、网格/表面分割、交互式可视分析或渲染时才考虑。
- **ICMR**：需要把问题改成医学图像检索、跨模态检索或“分割辅助检索”。单纯分割不匹配。
- **RECOMB**：需要计算生物学、组学或生物医学机制问题；普通医学图像分割不匹配。
- **UAI**：如果不确定性估计、校准、分布外检测是核心方法，可以考虑；普通分割网络不建议。
- **DCC**：只有压缩医学图像、压缩分割掩膜或压缩感知是主贡献时才考虑。
- **PPSN、EMSOFT、ISMAR、ICCBR**：分别需要进化优化、嵌入式实时部署、AR/VR 医学交互、案例推理等明确主题。

### 基本不建议用于普通医学图像分割

AAMAS、COLING、NAACL、ICAPS、COLT、KR、InterSpeech、WINE、CogSci、SCA，以及已经过期的 ECAI 2025、SPM 2025。它们的核心主题与医学图像分割主线不一致，除非论文同时解决其专门问题。

## 二、逐个判断与审稿周期

这里的“审稿周期”指**投稿截止日至首轮录用/拒稿通知之间的公开日程间隔或近届常见范围**。会议通常不会承诺固定审稿天数，实际还可能包括 rebuttal、修改、shepherding 和最终注册环节。

| 会议 | 医学图像分割匹配度 | 适合什么论文 | 常见首轮周期 | 对你当前方向的建议 |
|---|---|---|---|---|
| **MICCAI 2026** | 直接匹配 | 医学图像分割、检测、配准、手术导航、医学视觉基础模型 | 约 **3个月**，常见 10–14 周 | **首选**。需要医学问题、严谨基线、患者级划分和充分消融 |
| **BIBM 2026** | 直接匹配 | 生物医学图像分析、医学数据建模、分割和预测 | 约 **2–3个月**，常见 6–12 周 | **很适合**。通常比 MICCAI 更容易容纳应用型医学分割工作 |
| **ECCV 2026** | 高，但竞争很强 | 通用视觉方法、泛化、弱监督/半监督、跨域医学视觉 | 约 **3–4个月**，常见 12–16 周 | **高风险冲刺**。必须证明方法超出单一医学任务的价值 |
| **ICASSP 2027** | 条件匹配 | 频域、多尺度信号处理、噪声鲁棒、医学影像重建或分割 | 约 **2–3个月**，常见 8–12 周 | 只有信号处理是主线时投；普通注意力模块不够 |
| **ICME 2026** | 条件匹配 | 医学视频、3D 影像、多模态医学媒体分析 | 约 **2–3个月**，常见 8–12 周 | 需要明显的多媒体属性；普通 2D 分割不建议 |
| **IJCAI 2026** | 条件匹配 | 通用 AI 学习算法、推理、不确定性、跨任务泛化 | 约 **2–4个月**，常见 10–16 周 | 论文核心必须是 AI 方法；医学数据只能作为验证场景 |
| **ICRA 2027** | 条件匹配 | 手术机器人、术中视觉、机器人三维感知 | 约 **3–4个月**，常见 12–16 周 | 没有机器人或术中场景时不建议 |
| **Eurographics 2027** | 条件匹配 | 医学三维可视化、表面重建、体绘制、交互式分析 | 约 **4–6个月** | 普通 CNN/Transformer 分割不匹配 |
| **EuroVis 2026** | 条件匹配 | 分割结果可视分析、医生交互、可解释可视化 | 约 **3–5个月** | 可视分析必须是主要贡献 |
| **PG 2026** | 条件匹配 | 医学三维图形、几何建模、可视化和渲染 | 约 **3–4个月** | 更适合 3D 几何和图形学论文 |
| **SGP 2026** | 条件匹配 | 形状分析、网格分割、几何深度学习 | 约 **3–5个月** | 要有几何处理问题，不是普通像素分割 |
| **EGSR 2026** | 弱匹配 | 医学渲染、光照、体绘制 | 约 **3–5个月** | 仅做医学分割不建议 |
| **ICMR 2027** | 弱到条件匹配 | 医学图像检索、分割辅助检索、跨模态检索 | 约 **2–3个月** | 需要检索任务和检索指标 |
| **RECOMB 2027** | 弱到条件匹配 | 计算生物学、组学和生物医学机制 | 约 **2–3个月** | 普通器官/皮肤/息肉分割不建议 |
| **UAI 2026** | 条件匹配 | 不确定性、校准、分布外检测、可靠医学分割 | 约 **3–4个月** | 不确定性必须是核心贡献 |
| **DCC 2027** | 弱匹配 | 医学图像或掩膜压缩、压缩感知 | 约 **2–3个月** | 论文主线必须是压缩 |

## 三、对你当前 EMCAD 类论文的具体排序

如果论文仍然是“改进医学图像分割网络，在 BUSI、ISIC、Polyp、ACDC、Synapse 等数据集上比较 Dice、IoU、HD95”，建议顺序为：

1. **MICCAI**：最符合领域，但要求实验设计和医学解释更严格。
2. **BIBM**：适合应用型医学图像分割和生物医学数据论文。
3. **ECCV**：只有在方法具有通用视觉意义、跨数据集泛化和强对比时再冲。
4. **ICASSP**：只有论文确实围绕信号处理或频域方法组织时考虑。
5. **IJCAI**：只有算法创新足以脱离医学应用场景时考虑。

不建议为了“CCF-B”把普通分割论文硬改投 Eurographics、ICMR、RECOMB 或 ICRA。会议等级相同不代表研究主题相同，主题不匹配会在送审前或外审阶段直接吃亏。

## 四、投稿前必须核对的事项

- **患者级划分**：同一患者的切片、帧或增强图像不能跨训练、验证、测试集。
- **验证集选模型**：不能用测试集 Dice 选择 checkpoint 或调参。
- **完整指标**：至少报告 Dice、IoU；医学分割通常还应报告 HD95、ASSD 或敏感性/特异性。
- **逐病例结果**：不能只给全数据集平均值，应报告病例级均值、标准差和失败案例。
- **消融实验**：分别验证多尺度模块、注意力模块、监督策略、损失函数和输入设置的贡献。
- **公平比较**：统一输入尺寸、训练轮数、增强策略、预训练设置和数据划分。
- **统计检验**：多数据集比较时报告置信区间或配对统计检验，避免只强调单次最高 Dice。
