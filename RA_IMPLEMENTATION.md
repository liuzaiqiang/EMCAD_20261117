# EMCAD + PraNet-style RA: implementation and reporting

References: Fan et al., *PraNet: Parallel Reverse Attention Network for Polyp Segmentation*, MICCAI 2020, §2.2, https://arxiv.org/abs/2006.11392 ; authors' PyTorch code, https://github.com/DengPingFan/PraNet/blob/master/lib/PraNet_Res2Net.py .

This project implements **one RA refinement stage at EMCAD's d2-to-d1 transition**, not the full PraNet. PraNet uses a Res2Net backbone, a parallel partial decoder and three RA stages. EMCAD already has four decoder heads, so the d2 head supplies the coarse logits, and d1 is the finer feature map. The implementation follows the author's RA2 sequence: upsample coarse logits; invert the foreground prediction; multiply the finer feature by that reverse attention map; apply 1×1/3×3/3×3/3×3 convolution and batch normalization with ReLU after the middle convolutions; add the predicted logit residual to the upsampled coarse logits. The output remains raw logits and is passed through the existing training and evaluation code.

The author's RA code addresses **binary** masks. For the five binary polyp datasets, two ISIC datasets, BUSI, DSB18 and EM, the gate is exactly `1 - sigmoid(coarse_logits)`. For Synapse and ACDC, class 0 is background and the gate is `softmax(coarse_logits)[:, 0:1]`, the complement of total foreground probability. This is an explicit multiclass adaptation, not a claim that the original PraNet code was evaluated on those datasets. Interpolation uses the d1 spatial size rather than a hardcoded factor, to avoid shape errors across supported image sizes and encoders.

`RA_ENABLED=0|1` in training `.sh` scripts maps to `--ra_enabled`, default `0`. With `0`, the original EMCAD final 1×1 head remains. With `1`, RA replaces that head. The small-target hard-region loss remains an independent switch and acts on the final logits. Training configuration and model files distinguish the RA setting; testing restores the setting from the saved training configuration, defaulting to `0` for older configs. Synapse topN candidate selection and Dice/HD95 history are unchanged.

Complexity reporting calls this project's original `utils.utils.CalParams(model, input_tensor)` with a single image at the dataset's configured resolution and input channel count, and persists its exact THOP/`clever_format` output in `model_complexity.txt`. The file also contains an independently counted exact number of registered parameters. THOP's field called FLOPs is its own single-forward estimate, and does not include every functional tensor operation; it is not a measurement of training cost. THOP temporary counting buffers are removed after reporting. For paper comparisons, report the input shape, tool/version and this convention consistently. PraNet's published Dice improvements are evidence for its own architecture and datasets, not a guaranteed gain for this EMCAD adaptation.
